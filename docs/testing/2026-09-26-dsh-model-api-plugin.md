# 模型 API 插件验收

新增独立安装的 `@johnason/dsh-model-api` 插件，为 Agent 应用提供本地 LLM 与外部云模型配置。入口为「插件 → 已安装 → model-api」，原生「设置 → 模型」页底部也有同一表单。官方子模块仍为 `ddefc45fbc7f8e46dd73185e68295696d1297887`，没有改动官方推理或凭据接口。

## 行为与边界

- 使用原生 Settings Remote 向 `llm-pi-ai.providers.johnason-<id>` 新增一条连接，支持 OpenAI Chat Completions、OpenAI Responses、Anthropic Messages。已有连接通过原生 Models 编辑；本插件不替换或删除既有连接。
- API Key 仅经 Credentials Remote 保存到加密 Vault；模型配置保存独立随机凭据引用，不回显密钥。未认证的本地接口使用 Vault 内的随机占位值。Vault 锁定时明确提示先解锁。
- 本地地址限制为 loopback HTTP/HTTPS；外部地址要求 HTTPS。拒绝 URL 用户信息、查询参数及片段。保存不会探测服务或自动发送模型请求。
- 重复 ID 拒绝；重复检查和提交使用同一份配置版本。保存期间刷新不会绕过版本冲突保护。凭据状态按原生每批最多 64 项分批读取。
- 两个本地 UI 插件均遵循原生安装、停用与卸载状态，启动器不会自动重新启用已停用插件。停用或卸载入口不会删除模型配置、Vault 或历史。

## 限制

本次“外部 API”按云模型接口实现，普通业务 API 继续由系统插件管理。插件为应用设置界面，不新增模型自主改写连接或传递密钥的聊天工具。云服务实际兼容性需用户录入自己的服务地址、精确模型 ID 与凭据后验证。

Vault 与设置文件是两个独立存储：若凭据写入成功、配置提交发生版本冲突，会保留尚未引用的加密凭据，界面提示刷新后重试；同一草稿重试沿用凭据引用，不擅自删除数据。旧版记忆数据迁移仍属原有独立待办，不在本次改动范围。
