- 日期：2026-09-08；代码基线 `af3080f`，仅新增 `apps/dsh-agent` 启动器、凭据接口、页面及测试夹具；原有三引擎控制面不在范围内。
- 按 `agent-security-scan` 技能进行一次集中人工检查：执行入口、依赖固定、凭据流向、页面输出、文件发布和扩展边界。未反复执行全仓扫描。
- `agt`、`gitleaks`、`detect-secrets` 本机不可用；未自动安装。以定向源码检索和真实负向测试替代，不声称完成这些工具的扫描或完整 CVE/SBOM 审计。
- 生产薄层不增加独立外部依赖；原生依赖由锁定子模块 `b150a551b8d465e31e418e1b2eaf5e79bbb7d28e` 及其 pnpm 锁文件提供。刷新回归测试另固定 devDependency `playwright-core@1.62.1` 及 package-lock，使用本机 Google Chrome 的隔离测试 profile，正式启动不加载它；该测试依赖未另行做完整漏洞数据库审计。固定版本不代表不存在已知漏洞。
- GitHub/OpenAI/AWS/Slack 常见密钥格式的仅文件名检索无匹配；并检查启动器未继承模型密钥变量、未调用 `.env` 加载器。有限格式检索不能排除所有秘密形态。

## 保留限制

1. 主密码和解密记录在使用时必然进入本进程内存；清空输入框/Buffer 不保证 JavaScript 字符串被立即物理擦除。已解锁进程中的受信任插件可调用凭据服务。
2. 本机进程可发起 HTTP；同源检查不防御已控制本机的攻击者。没有多用户鉴权或专门暴力破解限速，不可直接暴露公网。
3. 第三方 Skill/MCP/插件和模型生成 HTML 应按其原生权限边界审查；本报告没有对任意外部扩展作安全背书。
4. 锁定阻止后续凭据读取，不撤回已发出的云请求，也不取消历史任务。旧系统的 31 条历史任务保持原先暂停状态，本应用不接入它们。
