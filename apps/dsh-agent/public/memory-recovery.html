双时态审计

事实时间：发生了什么；系统时间：当时已经知道什么。时间使用 UTC，留空表示最新。查询返回各记录在该时点的有效版本，不是完整状态变更流水。

UNKNOWN = 执行结果未知，不能自动重跑。COMMITTED 仅代表结果已确认，不等于业务成功。因果仅来自显式 parent / causation 边，不能由时间推断。普通记忆不自动生成 Effect 证据。
