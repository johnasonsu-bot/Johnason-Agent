Ruling: accepted Query with durable acceptance and no Tool-start follows the approved federation design and may retry on the same fixed Runtime; write-start is persisted before execution, and any unmatched/unknown write forces reconciliation — cost if wrong: an unsafe write replay or an unnecessarily blocked retry.
Ruling: immediate process failure gets a new fenced `recover_failed_lease` path while application restart without proof of old-process death waits for lease expiry — cost if wrong: delayed recovery up to the lease deadline, chosen to avoid concurrent old/new owners.
Ruling: Effect evidence becomes append-only per cursor while the existing aggregate row remains a compatibility projection — cost if wrong: schema and recovery complexity increase, but multi-Tool Queries remain representable.
Ruling: manual `disabled` persists across live re-registration; crash uses transient withdraw under Supervisor generation CAS — cost if wrong: an operator-disabled Runtime could otherwise silently reactivate, or a stale callback could withdraw a fresh process.
Task RF-2B brief review round 2: 3 Critical and 4 Important findings; all resolved before implementation.
Ruling: callers can create only attempt 0; every later attempt is atomically created by a one-time durable retry outcome at exactly source attempt + 1 — cost if wrong: a caller could bypass recovery policy or replay an outcome.
Ruling: a portable process guard plus private containment lock proves prior sidecar termination; cleanup-unconfirmed blocks restart and retry delivery — cost if wrong: availability is sacrificed when containment cannot be proven, chosen to prevent concurrent old/new sidecars.
Ruling: Effect evidence identity includes run/term/step/cursor, not cursor alone — cost if wrong: multi-Step Queries would collide or evidence could be attached to the wrong Step.
Ruling: crash restart budget is cumulative per Supervisor lifecycle and never reset by a handshake; clean recycle is excluded — cost if wrong: a crash-after-handshake loop could restart forever or normal Query turnover could exhaust the budget.
